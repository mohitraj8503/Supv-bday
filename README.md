# 🎉 Happy Birthday Jiya - Widescreen & Mobile Celebration Website

A modern, responsive, 16:9 widescreen & mobile-optimized Birthday Celebration Web Application built for Jiya!

## 🚀 Features
- 🖼️ **AI Background Removal**: High-precision portrait matting with zero edge halos.
- 📺 **16:9 Widescreen & Mobile First**: Seamless viewport scaling across desktop monitors and mobile smartphones.
- 🎈 **Festive Interactive Assets**: Floating 3D glass spheres, cake candles, garland banners, and balloon borders.
- 📱 **Direct WhatsApp Wish**: Custom wish form that routes directly to WhatsApp (`+91 86769 92907`).
- 🎵 **Background Music & Confetti**: Real background audio track with fallback Web Audio synthesizer and confetti explosions.

## 📦 How to Deploy on GitHub Pages

1. **Initialize Git Repository & Commit**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Happy Birthday Jiya website"
   ```

2. **Push to GitHub**:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your repository on GitHub.
   - Click **Settings** -> **Pages** (under Code and automation).
   - Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
   - Choose Branch: `main` and Folder: `/ (root)`, then click **Save**.
   - Your site will be live at `https://<your-username>.github.io/<your-repo-name>/` in 1-2 minutes! 🥳
